## multi-多本計算機
> 快速總覽/計算想買的清單書籍中適用什麼方案，試算下來需要花多少價錢。
 - 「*」鍵 短按可自訂折扣 | 長按叫出（偽）乘法機制，快速加入多本相同價格的書進清單。
 - 「一鍵套用」可迅速將所有清單內的書套用指定的打折方案（推薦方案/7折/75折/8折/自訂折扣）。
